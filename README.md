# Sawaaden Tours & Travels

A responsive, SEO-focused travel agency website for **Sawaaden Tours & Travels**, Gangtok, Sikkim.

## Features
- Sikkim-focused SEO metadata and semantic HTML
- TravelAgency JSON-LD structured data
- Responsive mobile navigation
- Sikkim, North Sikkim, East Sikkim and Silk Route sections
- Darjeeling and custom-tour positioning
- WhatsApp and phone enquiry buttons
- Google Maps and Facebook links
- FAQ content
- `robots.txt` and `sitemap.xml`
